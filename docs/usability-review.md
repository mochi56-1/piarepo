Figma：`https://www.figma.com/design/2hrOVXkUW3viFItJd34YqR/?node-id=0-1`。リンクからの取得はできませんでしたが、続けて提供された「ぴあれぽ.pdf」（13ページ）を全ページ確認し、デザインと新画面を実装しました。詳細は [Figma書き出しへの対応](figma-design.md) を参照。

## 実装

## まだ実装しないもの・限界

- Figmaのインタラクティブなプロトタイプ自体は未取得。ユーザー提供の書き出しPDFをデザイン資料として確認済み。
- 本当の友だち招待・オンライン共有・他人からの通知はバックエンド未導入のため未実装。つながり一覧と広場は端末内のお試し機能。通知の表示設定だけ保存。
- コイン、成長、ログインボーナスなどのゲーム要素、定期的な自動振り返りは、体験設計を決めてから追加する。義務感を減らす意見と両立させる必要がある。
- Safariの音声認識をこの修正だけで全環境に対応させることはできない。対応状況とキーボードの音声入力を案内する。
- 現在の記録は引き続きlocalStorage。自分の気づき・履歴は端末内でのみ保持。将来のバックエンド導入時は、本人だけが読める権限を別途実装する必要がある。
- ユーザー確認後、コミットのみ実施。push・公開は別途指示後に行う。

- `npm run build`：本番ビルド。
- Chromiumで、作成モーダル、任意タイトル・写真のみ、日付連動、カード本文からの詳細、編集履歴、自分だけの気づき、公開範囲、スタンプ、コメント候補、画面維持、つながり、バックアップのダウンロードと確認後の復元、通知設定、前の週、320〜1440px幅、容量不足時の入力保持を検証。
- 実機iPhone・実マイク・実ユーザー間共有は未検証。デザインはFigma書き出しPDFと照合。
