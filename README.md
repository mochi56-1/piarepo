# ぴあれぽ

やわらかな色合いのジャーナリング共有アプリのフロントエンド。

## 開発

Node.js 24 / npm 11 で検証。

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

`npm run build` で本番ビルド。

## 使い方

- **カレンダー**：日を選ぶと、その日の自分のnoteを一覧表示。月・年の切り替えと過去の日付への記録に対応。
- **note**：日本語の音声入力に対応（対応ブラウザ・HTTPSまたはlocalhost・マイク許可が必要）。確定した認識結果を本文に追記し、聞き取り中の仮テキストは保存しません。録音ファイルは保存しません。音声認識はブラウザの外部サービスで処理される場合があります。手入力は常に利用できます。
- **気分・画像**：5段階の表情で気分を選び、文章と画像1枚（JPEG / PNG / WebP / GIF、2MB以下）を保存。
- **広場**：ストーリーのないタイムライン。サンプルのnoteと「広場にも置く」を選んだ自分のnoteを表示。
- **マイページ**：自分の記録をまとめて表示。

noteは初期状態で「自分だけ」。すべてのデータと添付画像はブラウザのlocalStorageに保存され、広場も同じブラウザ内でのお試し表示です。実際のユーザー間共有やログインは未実装で、バックエンドの追加が必要です。端末やブラウザを変えると同じ記録は表示されません。

旧バージョンの保存キーを維持し、以前の記録と気分を引き継ぎます。日付のない自分の記録は作成時刻から日付を復元し、従来のサンプルには2026年10月13日を使用します。保存容量が不足した場合はエラーを表示し、入力中の内容を残します。

サンプル画像: Cruip Open React Template（人物）、Bedimcode Responsive Coffee Website（コーヒー）、ianare/exif-samples（街並み）。ノートのイラストは本アプリ用に作成。

## iPhoneで使う

Vercelの公開HTTPS URLをSafariで開き、共有メニューから「ホーム画面に追加」を選択。アイコン・アプリ名・standalone表示を設定済みです。音声認識の利用可否はブラウザと起動モードに依存します。音声入力ボタンが利用できない場合はiPhoneのキーボードの音声入力を利用してください。

オフライン対応や端末間同期はありません。保存は起動したブラウザ／ホーム画面アプリのlocalStorageです。ホーム画面への追加時に、既存のSafariの記録が引き継がれることを前提にしないでください。実機のインストール・マイク操作は別途確認が必要です。
