# ぴあれぽ

ミント色の部屋で、気持ちと日々の予定を残すジャーナリングアプリのフロントエンド。

## 開発

Node.js 24 / npm 11 で検証。

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

`npm run build` で本番ビルド。

## 使い方

- **ホーム**：いま・次の予定とキャラクター。気持ちの記録やスケジュールへ移動。
- **タスク**：リストで完了を切り替え、マップでピン配置を変更。
- **スケジュール**：日付と時刻で予定を作成・編集。タスクマップから追加、重複する予定は別列に表示。

- **カレンダー**：日を選ぶと、その日の自分のnoteを一覧表示。月・年の切り替えと過去の日付への記録に対応。
- **note**：日本語の音声入力に対応（対応ブラウザ・HTTPSまたはlocalhost・マイク許可が必要）。確定した認識結果を本文に追記し、聞き取り中の仮テキストは保存しません。録音ファイルは保存しません。音声認識はブラウザの外部サービスで処理される場合があります。手入力は常に利用できます。
- **気分・画像**：5段階の表情で気分を選び、文章と画像1枚（JPEG / PNG / WebP / GIF、2MB以下）を保存。
- **広場**：ストーリーのないタイムライン。サンプルのnoteと「広場にも置く」を選んだ自分のnoteを表示。
- **マイページ**：自分の記録をまとめて表示。

noteは初期状態で「自分だけ」。すべてのデータと添付画像はブラウザのlocalStorageに保存され、広場も同じブラウザ内でのお試し表示です。実際のユーザー間共有やログインは未実装で、バックエンドの追加が必要です。端末やブラウザを変えると同じ記録は表示されません。

旧バージョンの保存キーを維持し、以前の記録と気分を引き継ぎます。日付のない自分の記録は作成時刻から日付を復元し、従来のサンプルには2026年10月13日を使用します。保存容量が不足した場合はエラーを表示し、入力中の内容を残します。

サンプル画像: Cruip Open React Template（人物）、Bedimcode Responsive Coffee Website（コーヒー）、ianare/exif-samples（街並み）。ノートのイラストは本アプリ用に作成。

## iPhoneで使う

Vercelの公開HTTPS URLをSafariで開き、共有メニューから「ホーム画面に追加」を選択。アイコン・アプリ名・standalone表示を設定済みです。音声認識の利用可否はブラウザと起動モードに依存します。音声入力ボタンが利用できない場合はiPhoneのキーボードの音声入力を利用してください。

オフライン対応や端末間同期はありません。保存は起動したブラウザ／ホーム画面アプリのlocalStorageです。ホーム画面への追加時に、既存のSafariの記録が引き継がれることを前提にしないでください。実機のインストール・マイク操作は別途確認が必要です。

## 第1回検証を受けた改善

短文・写真だけのnote、作成モーダル、編集前の履歴、本人だけのあとからの気づき、寄り添うスタンプ、コメント候補、スマホの週別振り返り、気分のカレンダー色、日付順のマイページを追加。詳細と未対応項目は [検証結果への対応](docs/usability-review.md) を参照。

マイページから記録をJSONで書き出し・復元できます。写真・気づき・編集履歴も含みます。読み込みには確認が必要で、同じIDはバックアップ内容で置き換え、それ以外の既存記録は残ります。バックアップは個人情報として自分で管理してください。つながり一覧の名前と通知設定はバックアップの対象外です。

バックアップの単体テスト：`node --test tests/backup.test.js`。

## Figma書き出しに合わせた新しい画面

ユーザー提供「ぴあれぽ.pdf」全13ページを参照し、ホーム・タスク・スケジュール・note・広場・カレンダーを実装。キャラクターは同PDFの埋め込み原画像を抽出し、SVGの表示範囲を指定して使用しています。デザインの対応表・採用した仮仕様は [Figma書き出しへの対応](docs/figma-design.md) を参照。

スマホの下部ナビは「タスク・note・ホーム・広場・カレンダー」。マイページは右上の本人アイコンから開きます。PCではサイドバーから全画面へ移動できます。スケジュールにはホームの「スケジュールを確認」、タスクのカレンダーアイコン、PCのサイドバーから移動できます。

タスクとスケジュールはブラウザの `piarepo-planner` に保存。noteの保存キー `moobin-posts` は維持しています。**現在のnoteバックアップには、タスク・スケジュール・つながり設定は含まれません。** ブラウザを変えた際の同期・オンライン共有・オフライン対応は未実装です。

テスト：`npm test`。ビルド：`npm run build`。

## ログインボーナス

ホームとマイページで1日10コインを受け取れます。連続ログインのリセットや減点はありません。Supabase未接続時はブラウザ内の「お試し」で、本番コインには引き継ぎません。Supabase接続後はメールのログインリンクで認証し、日本時間の日付とアカウントごとにサーバー側で1日1回に制限します。

まだSupabaseプロジェクトがないため、本番接続には [設定手順](docs/login-bonus.md) の実施が必要です。公開用の環境変数は `.env.example` を参照。**同期されるのはコインだけで、note・タスク・予定はまだアカウント別に分かれずブラウザ内の保存です。** 交換所・着せ替えは未実装です。


## Googleカレンダーへの追加

保存済みのスケジュールをクリックし「Googleカレンダーに追加」を選ぶと、タイトル・日時を日本時間で設定したGoogleの予定作成画面が別タブに開きます。Google側で保存してください。編集後はぴあれぽで先に保存し、予定を開き直して追加します。タスク由来の予定・直接作成した予定ともに利用できます。

Calendar APIや追加のOAuth権限は使いません。自動同期・追加済み判定・変更削除の反映はなく、再度保存すると重複する場合があります。タスクマップのピンから完了または予定追加もできます。完了したタスクはリストから未完了へ戻せます。既存の予定は残ります。
